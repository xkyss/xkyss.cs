# Launcher 需求

本仓库的示例工具 App:应用启动管理器。

## 双形态

- **窗口内管理**:活动栏切换启动项分类,侧边栏为列表 + 搜索过滤,编辑器区显示并编辑启动项详情,底部面板显示启动日志,状态栏显示运行状态。
- **全局热键浮层**:默认 `Ctrl+Alt+Space` 呼出悬浮搜索窗,输入过滤、回车即启动;与窗口内管理共用同一份启动项数据。

## 启动项模型

一个启动项包含:

- 名称
- 命令:程序路径 / 脚本 / URL
- 可选参数、工作目录
- 分类(决定活动栏分组)
- 可选图标(缺省取 exe 图标)
- 可选每项热键

## 数据源

- 单一 JSON 配置文件:`%APPDATA%\Mew\launcher.json`,可手写、可 diff。
- 启动项变更后自动保存;浮层与窗口内视图共享同一份数据。

## 常驻

- 托盘常驻:关闭主窗口不退出,热键随时呼出。
- v0.1.1 不做开机自启(可用启动文件夹快捷方式替代)。
