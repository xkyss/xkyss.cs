# 02 — 删除分类 = 摘除归属(永不删项)

**What to build:** 删除分类的语义从「连根删(连带删除启动项)」改为「摘除归属,永不删项」:从所有引用它的启动项上摘掉该分类,子分类随父分类整棵子树一并摘除;项还有其他归属则保留,一个归属都不剩则归「未分类」。删除确认框与删除后的界面刷新同步更新。

**Blocked by:** 01 — 多分类数据模型与迁移

**Status:** ready-for-agent

- [ ] 删除一个分类后,其下启动项不被删除
- [ ] 被删分类下、同时属于其他分类的启动项,仍在其所属分类下可见
- [ ] 被删分类下、一个归属都不剩的启动项,归入「未分类」
- [ ] 删除父分类时,子分类整棵子树一并摘除归属
- [ ] 删除确认框提示「N 个启动项将失去分类 X」,不再提示「删除 N 个启动项」
- [ ] 删除后侧边栏树、列表、详情刷新正确;详情正显示被删分类的项时,界面回退到「全部」或清空
