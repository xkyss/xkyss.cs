# 01 — 多分类数据模型与迁移

**What to build:** 启动项的归属从单值分类改为分类数组:每个启动项可挂多个分类(空数组 = 未分类),旧数据自动迁移,数据层的聚合与归一全部按数组语义工作,UI 组织行为与迁移前保持一致(单选行为不变)。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 旧 `launcher.json`(单值归属)加载后自动迁移为数组,启动项归属不变;原「未分类」项迁移后仍归「未分类」
- [ ] 手写 JSON 缺省归属字段的启动项被归一为空归属,归「未分类」
- [ ] 数据层聚合语义保持:选中父分类显示其子树(含子孙)全部项;「全部」显示所有项;「未分类」只显示空归属项
- [ ] 悬空引用(归属指向不存在的分类)的启动项被归一为「未分类」
- [ ] 保存后数据文件读写往返一致
- [ ] 数据层与存储的既有测试更新后全绿,UI 侧边栏/列表/详情显示与迁移前一致
