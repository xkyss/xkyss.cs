# 02 — 列表键盘导航与选中模型

**What to build:** 启动项列表获得焦点后支持 ↑/↓ 移动选中（环绕）、Enter 启动选中项、「/」或 Ctrl+F 聚焦搜索框；选中模型卡片/列表共用；选中态（accent 背景+左缘 accent 条）与悬停态（背景微亮）视觉区分。

**Blocked by:** 01 — 列表手势模型与悬停编辑.

**Status:** ready-for-agent

- [ ] 列表获得焦点后 ↑/↓ 移动选中并环绕，Enter 启动选中项。
- [ ] 「/」或 Ctrl+F 聚焦列表文档的搜索框（分类树搜索不受影响）。
- [ ] 选中态与悬停态视觉可区分：选中 = accent 背景+左缘条，悬停 = 背景微亮。
- [ ] 查询刷新后选中收敛到可见结果内，不越界。
- [ ] 选中移动/环绕/收敛逻辑抽为纯逻辑（与浮层循环选择同构，可共用实现），在现有测试项目补 xunit 用例（空列表、单元素、边界环绕、刷新收敛）。
