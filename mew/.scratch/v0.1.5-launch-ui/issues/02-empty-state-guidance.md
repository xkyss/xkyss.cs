# 02 — 空状态引导

**What to build:** 空状态分场景引导：「暂无启动项」显示图标+文案+「＋新增启动项」按钮；「无匹配启动项」「无匹配分类」显示图标+文案+「清空搜索」按钮；分类树侧边栏与启动项列表共用同一套空状态组件。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 「暂无启动项」提供「＋新增启动项」按钮，点击可新增。
- [ ] 「无匹配启动项」「无匹配分类」提供「清空搜索」按钮，点击清空筛选恢复内容。
- [ ] 三种空态与动作判定抽为纯逻辑并在现有测试项目补用例。
- [ ] 空状态组件颜色取自五区色板，亮/暗主题下均适配。
