# 01 — 列表单击启动与双击防重

**What to build:** 启动项列表（卡片/列表两形态）单击即启动该启动项；双击同一启动项不会重复启动（防重时间窗）；右键菜单「编辑/删除」保持可用。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 卡片与列表行单击即启动对应启动项。
- [ ] 双击同一启动项只启动一次（防重时间窗生效，不连开两次）。
- [ ] 右键菜单「编辑/删除」行为与现有一致。
- [ ] 防重判定抽为纯逻辑并在现有测试项目补用例（时间窗边界、同项/异项、恢复）。
