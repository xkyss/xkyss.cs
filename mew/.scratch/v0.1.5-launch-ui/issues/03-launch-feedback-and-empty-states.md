# 03 — 启动反馈与空状态引导

**What to build:** 启动成功静默（状态栏轻文字或完全静默），失败 toast + 状态栏红字，输出面板照记日志；空状态分场景引导组件——「暂无启动项」→ 图标+文案+「＋新增启动项」按钮，「无匹配启动项」「无匹配分类」→ 图标+文案+「清空搜索」按钮，侧边栏与列表共用一套组件。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 启动成功不弹打扰性提示（状态栏轻文字或静默）。
- [ ] 启动失败弹出 toast，状态栏以红色显示失败信息，输出面板照记日志。
- [ ] 「暂无启动项」显示图标+文案+「＋新增启动项」按钮，点击可新增。
- [ ] 「无匹配启动项」显示文案+「清空搜索」按钮，点击清空并恢复列表。
- [ ] 「无匹配分类」显示文案+「清空搜索」按钮。
- [ ] 空状态类型判定抽为纯逻辑（导航+查询 → 空态类型与动作），在现有测试项目补 xunit 用例。
