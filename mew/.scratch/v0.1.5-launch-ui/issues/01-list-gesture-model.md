# 01 — 列表手势模型与悬停编辑

**What to build:** 启动项列表（卡片/列表两形态）改为「单击=启动」：双击忽略（防重时间窗，避免单击启动后双击连开两次）；行尾常驻「启动」按钮移除，改为悬停浮现的「编辑」按钮（卡片角落、列表行尾）；右键菜单「编辑/删除」保留不变。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 卡片与列表行单击即启动该启动项。
- [ ] 双击同一启动项不会重复启动（防重时间窗生效）。
- [ ] 行尾「启动」按钮移除；悬停时卡片角落与列表行尾浮现「编辑」按钮，点击进入详情编辑。
- [ ] 右键菜单「编辑/删除」行为与现有一致。
- [ ] 双击防重判定抽为纯逻辑，在现有测试项目补 xunit 用例（时间窗边界、同项/异项、恢复）。
