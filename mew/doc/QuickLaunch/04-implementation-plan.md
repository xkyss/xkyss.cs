# 04 实现计划（简版）

## 目标

实现一个最小可用的导航站插件：
1. 左侧两级分类
2. 右侧卡片
3. 点击卡片启动

---

## 范围

MVP 内：
1. ActivityBar 单入口（⚡）
2. SideBar 两级导航
3. ContentArea 卡片网格
4. 启动 Web/App/Script
5. 当前分类搜索
6. 配置持久化

MVP 外：
1. 复杂设置页
2. 拖拽排序
3. 使用统计
4. 全局命令面板

---

## 开发步骤

1. 数据模型
- LaunchCategory（一级/二级分类）
- LaunchItem（卡片）

2. 服务层
- 加载配置
- 按分类查询卡片
- 启动目标
- 保存配置

3. UI 层
- SideBar：两级导航
- ContentArea：卡片网格
- 选择分类后刷新卡片

4. 交互层
- 点击卡片直接启动
- 搜索仅作用于当前分类

5. 验证
- Web/App/Script 三类都能启动
- 分类切换和搜索正常

---

## 预估工时

1. 模型和服务：1 天
2. SideBar 两级导航：1 天
3. ContentArea 卡片：1 天
4. 联调和验证：0.5-1 天

总计：约 3.5-4 天

---

## 交付标准

1. 左侧能切换两级分类
2. 右侧正确显示对应卡片
3. 点击卡片立即启动目标
4. 搜索只过滤当前分类卡片
5. 配置重启后仍然生效
