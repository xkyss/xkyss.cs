# 02 界面设计（ASCII）- 导航站简版

## 设计原则

1. 只做导航站，不做复杂管理后台
2. 左侧两级分类，右侧卡片
3. 卡片点击即启动

## SideBar 设计（两级）

### 结构

```
一级分类
└─ 二级分类
```

示例：

```
▼ 工作
  ├ 常用网站
  └ 本地工具

▼ 开发
  ├ 文档
  ├ 工具
  └ 脚本

▶ 娱乐
```

### 交互

1. 点击一级分类
- 仅展开/折叠

2. 点击二级分类
- 右侧刷新卡片列表

3. 搜索框
- 仅过滤当前二级分类中的卡片

## ContentArea 设计（卡片）

### 卡片网格

```
┌──────────────────────────────────────────────────┐
│ 标题: 工作 / 常用网站                             │
├──────────────────────────────────────────────────┤
│ [🐙 GitHub]      [📧 Gmail]      [📅 Calendar]  │
│ 版本控制平台      邮件系统         日程管理        │
│                                                  │
│ [🗂 Notion]      [🔍 Google]     [📰 HN]        │
│ 文档协作          搜索             新闻            │
└──────────────────────────────────────────────────┘
```

### 单张卡片

```
┌──────────────────────┐
│ 🐙 GitHub            │
│ 版本控制平台          │
│ Web: github.com      │
└──────────────────────┘
```

### 卡片交互

1. 单击卡片
- 立即启动

2. 右键卡片（可选）
- 启动
- 编辑
- 删除

## 响应式约束（简版）

1. 窗口较窄时
- SideBar 固定最小宽度
- Card 区自动换行

2. 卡片尺寸
- 统一宽高，防止跳动
- 标题超长省略

---

## 最小可实现版本（MVP）

1. ActivityBar 一个按钮
2. SideBar 两级分类
3. ContentArea 卡片网格
4. 点击卡片启动
5. 当前分类搜索
