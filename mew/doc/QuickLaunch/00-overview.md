# QuickLaunch 快速启动工具 - 总体设计

## 核心定位

QuickLaunch 只是 MewPad 的一个插件入口（ActivityBar 中一个按钮），交互逻辑保持简单：

1. 左侧 SideBar：两级分类导航
2. 右侧 ContentArea：启动卡片
3. 点击卡片：直接启动

支持启动类型：
- Web（网址）
- Application（本地程序）
- Script（命令/脚本）

---

## 界面模型

```
┌──────────────────────────────────────────────────────┐
│ MewPad 主窗口                                        │
├──────────────────────────────────────────────────────┤
│ ActivityBar | SideBar(两级导航) | ContentArea(卡片) │
│                                                    │
│ ...  ⚡ ... | ▼ 工作              | [GitHub]       │
│           |   ├ 常用网站         | [Gmail]        │
│           |   └ 本地工具         | [VS Code]      │
│           | ▼ 开发               | [npm]          │
│           |   ├ 文档             | [PowerShell]   │
│           |   └ 工具             | [...]          │
└──────────────────────────────────────────────────────┘
```

说明：
- ActivityBar：仅一个 QuickLaunch 按钮
- SideBar：只做导航，不做复杂编辑
- ContentArea：只做卡片展示和启动

---

## 最小功能

1. 两级导航
- 一级：业务分类（工作、开发、娱乐）
- 二级：子分类（网站、工具、脚本）

2. 卡片启动
- 卡片内容：图标、名称、描述（可选）
- 点击卡片直接启动目标

3. 基础搜索（可选）
- 在当前分类内过滤卡片

---

## 验收标准

1. 点击 ActivityBar 的 QuickLaunch 可以进入该视图
2. SideBar 可展示两级分类并切换
3. ContentArea 按当前分类显示卡片
4. 点击卡片可启动 Web/App/Script
5. 配置可持久化
