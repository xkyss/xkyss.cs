运行时异常：WinForms 相关\n\n**原因**：.NET 10 的 WindowsDesktop SDK 配置\n\n**解决**：检查 .csproj 中的 `<TargetFramework>` 和 `<UseWindowsForms>` 设置\n\n### 窗口无法显示\n\n**原因**：Platform Backend 配置（MewUI 需要平台支持）\n\n**解决**：\n- 确保在 Windows 10+ 环境\n- 检查 MewUI 依赖是否完整：`Aprillz.MewUI.Platform.Win32`\n\n---\n\n## 提交检查清单\n\n每日提交前：\n\n- [ ] 代码编译无错误/警告\n- [ ] 新接口/类已添加 XML 文档注释\n- [ ] 没有未使用的 using 指令\n- [ ] 没有硬编码的魔法数字（extract to
