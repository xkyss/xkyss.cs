# Issue 034: Plugin Catalog Metadata UI

## What to build

Show installed plugin package metadata in Runtime Diagnostics so local packages feel manageable rather than just loadable.

## Acceptance criteria

- [ ] Runtime Diagnostics shows installed package version and publisher metadata when available.
- [ ] Runtime Diagnostics distinguishes discovered, installed, disabled, incompatible, failed, and loaded states.
- [ ] Runtime Diagnostics shows install/update/uninstall results.
- [ ] Empty state explains where local packages can be installed from.
- [ ] Tests cover catalog state mapping outside the UI layer.
